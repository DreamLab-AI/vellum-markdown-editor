# Vellum icon

Vellum's original mark is an ivory sheet folded into a V, with an amber corner on
an ink navy rounded square. It replaces the icon inherited from upstream.

- Extension and README asset: [../../assets/icon.png](../../assets/icon.png), 256 × 256 PNG.
- Generated master: [icon-master.png](icon-master.png), 1254 × 1254 PNG.
- Checked at 32 × 32 for the extension list. The package manifest already points to
  `assets/icon.png`.
- Created with the built-in image generation tool, 2026-11-14. The generated master
  was downscaled with ImageMagick; no upstream artwork was used as a reference.
